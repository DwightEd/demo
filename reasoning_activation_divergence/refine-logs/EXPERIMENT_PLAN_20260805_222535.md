# ProcessBench 首错边界图监测实验计划

**冻结时间**：2026-08-05 22:25:35（Asia/Shanghai）  
**方法名**：Residual Depth Graph Monitor（RDGM，残差深度图监测器）  
**任务**：在当前推理步骤尚未生成时，判断该步骤是否将成为首错步骤。  
**状态**：代码已构建并完成本地合成/契约测试；真实四域 smoke/full 尚未在远端运行。

## 1. 研究问题与主张边界

主要问题不是“错误步骤写完后是否可被分类”，而是：

> 在步骤 `t` 的第一个 token 尚未生成时，模型各层残差状态是否包含可跨领域泛化的首错风险；真实层深邻接结构是否提供超出输出历史和无序层集合的增量？

允许的主张：

- pre-step residual-depth tensor 与首错发生存在前瞻性预测关联；
- 若真实深度图稳定胜过无序层和打乱邻接对照，则层深结构是有效的预测归纳偏置。

禁止的主张：

- Attention 路由导致了首错；
- FFN 缺少知识或更新失败导致了首错；
- 图模型的边权等于组件因果效应；
- ProcessBench 自然数据能够单独识别 Attention/FFN 根因。

Attention/FFN 根因仍属于 CFEA 的受控反事实干预分支；本实验只解决检测。

## 2. 时间安全的数据合同

对于步骤 token 区间 `[a_t,b_t]`：

```text
decision_position q_t = a_t - 1
state X_t = [h_1(q_t), ..., h_L(q_t)]  in R^(L x D)
label y_t = 1[t == first_error_step]
```

风险集：

- 错误链只保留 `t=0..first_error_step`；
- 正确链保留全部步骤；
- 保留 step 0，其状态来自 prompt 最后一 token；
- 删除首错后的全部行。

输入只来自：

```text
$DATA_ROOT/<domain>/geometry/trace.npz
$DATA_ROOT/<domain>/geometry/trace.states.pre.*.npy
```

`step_pre_state` 必须是 `h[a_t-1]`。不接受 step mean、step end、当前步骤 token、post-step Attention/MLP 或后续答案信息作为监测输入。

输出历史对照只使用已完成的 `0..t-1` 步 entropy/NLL；当前步骤的输出摘要不得进入特征。

## 3. 模型与反证对照

### M0：nuisance

只使用候选步骤编号、可见 prefix 长度、过去步骤长度和 step-0 标记。用于测量长度/位置污染。

### M1：output_history

M0 加已完成步骤的最后/平均 entropy、NLL。当前步骤输出不可见。

### M2：layer_set

输入完整 `[L,D]` 张量，但使用共享投影后做 permutation-invariant mean/max pooling；删除层序和邻接。它回答“完整 hidden 有信息，但图是否必要”。

### M3：depth_graph_shuffled

使用与主模型相同的图结构和训练配置，但用 3 个预注册 topology seed 重接层深邻接。每个置换都必须与原无向深度链具有零边重合；反序这类仍保留原邻接的置换不得作为 shuffled control。报告每个 seed 与 ensemble。

### M4：depth_graph（主模型）

每层状态经共享可学习投影后，在链图

```text
1 -- 2 -- ... -- L
```

上做前驱/后继消息传递，加入层位置嵌入，再用 gated pooling 形成风险 logit。原始 hidden 维直接进入可学习投影，不先压成手工标量、PCA 指标或 Ridge innovation。

## 4. 数据划分与训练

- 外层：四域 leave-one-domain-out；
- 内层：其余领域内按 `problem/sibling_group` 确定性划分训练/验证；
- 同题、同一 chain 的所有步骤永不跨 split；
- 状态均值/方差和上下文标准化只在内层训练行拟合；
- 训练损失按 domain→problem group→row 平衡；
- 验证集只用于 early stopping 和冻结正确链 false-alarm threshold；
- 主图与 shuffled graph 使用同一 fold seed 和超参数。

## 5. 主要指标

每条错误链在候选 `0..t*` 内排序：

- Top-1 localization；
- MRR。

正确链：

- correct-chain false-alarm rate；
- correct-step false-alarm rate。

辅助指标：问题组平衡的 NLL、AUROC、AUPRC。

主要配对增量：

```text
depth_graph - output_history
depth_graph - layer_set
depth_graph - depth_graph_shuffled
```

推断使用 domain→problem 的配对 bootstrap，报告 NLL improvement、Top-1 gain、MRR gain 和正确链误报下降的 95% CI。

## 6. 结果门槛

### 检测成立

`depth_graph` 相对 `output_history` 的 NLL improvement 95% CI 全部大于 0，且 Top-1/MRR 至少一个不恶化；正确链误报不能出现稳定恶化。

### 图结构成立

`depth_graph` 同时相对 `layer_set`、shuffled ensemble 和每个 shuffled topology seed 在 NLL 或链内定位上得到稳定正增量。若只胜输出基线而不胜这些结构对照，只能说完整 hidden tensor 有预测信息，不能说深度图有效。

### 否证结果

- `layer_set ≈ depth_graph`：层序/邻接没有增量；
- `shuffled ≥ depth_graph`：真实层邻接假设不支持；
- `output_history ≥ hidden arms`：内部状态没有可部署的独立增量；
- smoke 正、full/LODO 负：pilot 过拟合，不保留主张。

任何检测结果都不会自动通过 CFEA 的 routing/FFN root-cause gate。

## 7. 运行序列

```bash
bash run_hidden_geometry_remote.sh causal-monitor-smoke
bash run_hidden_geometry_remote.sh causal-monitor-full
```

smoke：每域 32 条 chain、3 epochs、200 bootstrap。  
full：每域全部 chain、20 epochs（patience 4）、2000 bootstrap。

每次运行产生：

```text
config.json
predictions.jsonl
summary.json
```

`summary.json` 的 `claim_scope` 固定为：

```text
predictive_association_not_attention_or_ffn_root_cause
```

## 8. 后续研究顺序

1. 先确认 pre-step 检测是否跨域成立；
2. 再用层遮蔽、边删除或 layer-pair intervention 定位结构贡献；
3. 只有受控 prefix counterfactual 与组件 patch 通过时，才进入 Attention routing / FFN update 根因分析；
4. 若图结构无增量，停止扩展 GNN，转向 token-source residual-message graph 的受控干预，而不是堆叠更复杂分类器。
