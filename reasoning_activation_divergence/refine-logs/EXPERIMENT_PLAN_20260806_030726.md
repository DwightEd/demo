# ProcessBench 两边界创新风险实验

**方法名**：Prefix-conditioned Two-Boundary Innovation Hazard（PTIH）

**冻结时间**：2026-08-06 03:07:26（Asia/Shanghai）

## 研究问题

在步骤 `t` 的第一个 token 尚未生成时，只使用合法前缀边界状态，检验相邻边界的有向更新
`H_t - H_{t-1}` 是否在位置、长度、过去输出统计以及当前静态 hidden state 之外，提供首错风险信息。

这是预测关联实验，不识别 attention 路由错误或 FFN 参数知识缺失。后两者需要受控成对轨迹和组件干预另行验证。

## 数据与无泄漏约束

- 状态：步骤开始前 `q_t = token_start_t - 1` 的 `[layer, hidden]`。
- 风险集：错误链保留 `0..t*`；正确链保留全部步骤；删除所有首错后步骤。
- 历史：步骤 `t>0` 使用 `(H_{t-1}, H_t)`；步骤 0 令 `H_{-1}=H_0`，因此创新量严格为零。
- 输出特征：只使用已完成的 `0..t-1` 步 entropy/NLL 汇总。
- 划分：外层按领域 LODO；内层按 problem/sibling group 划分；标准化只拟合训练行。

## 同容量实验臂

所有 hidden 实验臂共享完全相同的投影、池化和分类头参数量。

| 实验臂 | hidden 输入 | 要排除的替代解释 |
|---|---|---|
| `nuisance` | 无 | 步序、token 位置、历史步长 |
| `output_history` | 无 | nuisance + 过去输出不确定性 |
| `static_layer_set` | `P(H_t), P(0)` | 当前静态状态已经足够 |
| `two_boundary_bag` | `P((H_t+H_{t-1})/2), P(|H_t-H_{t-1}|)` | 只需两边界水平与变化幅度，不需方向 |
| `two_boundary_innovation` | `P(H_t), P(H_t-H_{t-1})` | 主模型：有向更新提供信息 |

`P` 是对每一层共享的可学习投影，再做 layer mean/max pooling；因此主实验不预设层邻接图，也不使用手工标量。

## 主要检验

主要人群为 `t>=1`，因为步骤 0 没有真实的前一边界。全风险集结果作为部署视角的次要结果。

1. `two_boundary_innovation - static_layer_set`：更新是否优于当前状态。
2. `two_boundary_innovation - two_boundary_bag`：更新方向是否优于无方向变化幅度。
3. `two_boundary_innovation - output_history`：内部状态更新是否优于可见输出历史。

主要统计量为 problem/chain 平衡 NLL 改善，使用 domain→problem 配对 bootstrap。Top-1、MRR、正确链误报率、AUROC/AUPRC 为辅助指标。

## 判定与停止条件

- 支持：在 `t>=1` 上，innovation 相对 static 和 bag 的 NLL 改善 95% CI 均高于 0，且正确链误报不恶化；各领域方向需报告。
- 部分支持：只胜 output 或 static，不能声称“有向更新”独有信息。
- 否定：innovation 不稳定胜过同容量 bag；停止继续扩大图结构或手工特征搜索。
- 无论结果如何，都不得从本实验声称 attention/FFN 根因。

## 执行阶段

1. 单元测试验证历史只来自同链合法前缀、三个 hidden 臂等容量、bag 对时间翻转不变。
2. 小样本 smoke 检查数据、训练、LODO、持久化和 paired bootstrap。
3. smoke 通过后运行全量四领域实验。
4. 依据停止条件决定是否进入受控 attention/FFN 干预阶段。

bash run_hidden_geometry_remote.sh causal-monitor-smoke
bash run_hidden_geometry_remote.sh causal-monitor-full
